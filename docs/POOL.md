# Против кого мерить

Короткий документ про одну вещь, на которой мы потеряли неделю: **соперник в
замере важнее самого замера.**

## Встроенные агенты среды не годятся

`kaggle_environments` даёт `pass`, `random`, `starter`. Вот что они берут
против настоящих ладдерных агентов (80 партий, оба места, дамп 5 сентября):

```
агент        побед       банк    соперник      разрыв
pass          0.0%      3,000     146,319    -143,319
random        0.0%          9     151,514    -151,505
starter       0.0%      3,551     146,522    -142,971
наш cem16    20.0%     60,482     106,391     -45,908
```

Стартовый капитал — 3 000. То есть **`starter` за весь сезон зарабатывает 551
монету**. Обыграть его — значит не разориться. Модель может уверенно бить
`starter` и стоять на минус ста сорока тысячах против живого поля.

Наши 20% — это не 20% силы: против восьми настоящих соперников из пула у нас
**ноль побед**, а выигрываем мы ровно у двух слабых эталонных агентов. Доля
побед против такого пула **насыщена** и не различает варианты; мерить надо
**разрыв банков**.

## Как собрать живой пул

Kaggle публикует дамп лучших партий каждый день. Он публичный.

```bash
# 1. свежий дамп (меняйте дату на вчерашнюю)
kaggle datasets download -d kaggle/kaggriculture-episodes-2026-09-05 --unzip -d /tmp/dump

# 2. выжать действия и индекс (~20 ГБ -> ~40 МБ)
python3 recon/extract_corpus.py /tmp/dump/<файл>.zip
#    -> corpus/actions/*.json.gz, corpus/index.csv

# 3. посмотреть, кто сейчас силён
python3 - <<'PY'
import csv, collections, statistics as st
rows = list(csv.DictReader(open("corpus/index.csv")))
agg = collections.defaultdict(lambda: [0, 0, []])
for r in rows:
    try: a, b = float(r["reward0"]), float(r["reward1"])
    except ValueError: continue
    for p, me, them in ((0, a, b), (1, b, a)):
        t = r[f"team{p}"]; agg[t][0] += me > them; agg[t][1] += 1; agg[t][2].append(me)
for k, (w, n, b) in sorted(agg.items(), key=lambda kv: -kv[1][0]/max(1,kv[1][1]))[:10]:
    if n >= 8:
        print(f"{k:28s} {n:3d} партий {100*w/n:5.1f}% банк {st.mean(b):,.0f}")
PY

# 4. сделать из эпизода самодостаточного агента (main.py-совместимого)
python3 recon/make_tape_agent.py <episode_id> <seat> --name tape_kwa
```

`recon/pool.py` собирает пул автоматически: `build_pool(n_strong=6)` берёт
шесть сильнейших политик по индексу плюс три реактивных эталонных агента.

## Оговорки, которые надо знать

* **Ленты разомкнутые.** Записанная партия проигрывается по номеру хода: она
  торгует на общем рынке и сбивает цены по-настоящему, но на ваши действия не
  реагирует. Это соперник слабее живого, а не сильнее.
* **Поле обновляется.** Хэш политики считается по последовательности действий,
  поэтому перезалив агента даёт новый хэш. Сильные игроки остаются, их версии
  меняются: из 488 хэшей дампа за 29 августа в дампе за 5 сентября осталось
  три, а единственный выживший просел с 75% до 41%. Пул надо пересобирать.
* **Меряйте на x86.** Агент, выбирающий работу через `argmax`, хаотичен по шуму
  округления: те же файлы побитово и те же сиды на arm64 и x86 дают разные
  партии (банк соперника отличался вдвое). Kaggle считает на x86.
* **Свой банк — плохая мерка.** Рынок общий: продали меньше -> цены выше ->
  соперник заработал больше. Три разных приёма подряд поднимали наш банк и
  ухудшали разрыв. Считайте `наш_банк - банк_соперника`.

## Смена поля, 9 сентября 2026: пул из лент устарел целиком

За первую неделю сентября на форуме вышли три полных агента, и все три --
**разомкнутые ленты**, а не политики: 13 заранее найденных потоков действий по
719 ходов, выбор ленты по первым двум лавкам на 144-м ходу, и тонкий
реактивный слой поверх (вставка `DIG` под сорняк, перенос продажи на ход
раньше, ликвидация на 718-м).

* `yhay81/shop-router-0909` -- автор стоит **#7 c 2874.1**
* `aurax7/kaggriculture-reactive-router` -- есть слой `_front_run`,
  опережающий продажи соперника по его же известной ленте
* `thomastschinkel/kaggriculture-public-state-router-74-5-win-rate`

Золотой порог на 9 сентября -- **2820.0** (топ-24 из 8320 команд). То есть
опубликованный агент сам по себе выше золота, и поле вокруг подскочило за
неделю.

### Замер, из-за которого пул пришлось менять

`shop-router` против прежнего пула, 40 партий, оба места против каждого из
десяти соперников:

```
доля побед  100.00% +/- 0.00      разрыв  +20 346 +/- 3 018
все 10 соперников: 100% побед на обоих местах
```

Ни одного поражения в 20 парах из 20. Прежний пул -- строго более слабый ярус.

### Чем это опасно было

Порядок пул угадывал верно, но **разницу сжимал в разы**:

```
                       на старом пуле        лоб в лоб
entity BC             +13 779 (74%)     ─┐
shop-router           +20 346 (100%)    ─┴─  entity BC  −4 169 +/-2 791
```

`cem16` на старом пуле давал 20% побед и выглядел «слабым, но живым». Против
живого поля у него **ноль из двенадцати** и −90 794 +/- 4 813. Полтора месяца
решений принимались по прибору, который скрывал именно тот разрыв, который
надо было видеть.

### Как пул устроен теперь

`recon/pool.py: build_pool()` по умолчанию ставит первым ярусом три публичных
агента, за ними прежние ленты и эталоны -- их можно отключить
(`include_tapes=False`, `include_refs=False`), и для решений о силе агента
надо отключать.

Каталог `recon/pubagents/` в gitignore: это чужой код под Apache-2.0.
Восстанавливается из Kaggle:

```
python3 recon/fetch_pubagents.py
```

### Инструменты

* `vs_agent.py` -- голова к голове против конкретного агента, парно, оба
  места, ошибка по парам.
* `probe_market.py` -- снимок рынка в партии клон против клона: цены,
  инвентарь, открытые лавки.
* `tapeswap.py` -- подмена культуры прямо в чужой ленте, для A/B портфеля.
